バッテリー情報の見やすさと、未接続時の案内を改善しました。

- バッテリー画面に、項目の長押しで説明を確認できる案内を追加しました。
- 記録・保護設定・充電値などの詳細を折りたたみ、必要なときに開けるようにしました。

既存の公開用署名による更新に対応しています。アプリ内の「情報」→「アップデートを確認」から更新できます。手動の場合は `OneTools-1.10.0.apk` をダウンロードしてください。

`update.json` と `SHA256SUMS.txt` はアプリ内更新とファイル検証に使用します。GitHubのSource codeアーカイブは開発者向けです。
