# OneTools

Samsung Galaxy向けの非公式ツールアプリです。バッテリーの情報や端末の設定を確認できます。

Samsung Electronicsとは提携・関連していません。

## ダウンロード

[最新版のAPKと変更履歴](https://github.com/fun7772ei/OneTools/releases/latest)

Releaseの「Assets」から `OneTools-1.8.1.apk` をダウンロードしてください。`Source code` のZIP・tar.gzはアプリ本体ではありません。

## 対応環境

- Android 11以降のSamsung Galaxy
- Shizuku（一部の情報取得・設定操作に必要）
- 開発時の実機検証はGalaxy S25。機種・One UI・地域により取得できる情報や設定操作は異なります。

## 主な機能

- バッテリー残量・温度・電圧・充電状態の確認
- Samsungの健康度報告値、推定サイクル数、充電保護などの確認
- バッテリーの残り使用時間の目安
- Samsungのシャッター音強制設定の確認・変更
- 型番・販売元に対応したSamsung公式の端末更新履歴へのリンク
- ライト／ダーク表示、タブ間のスワイプ、引き下げによる情報更新

値の意味や計算方法は、アプリ内の項目を長押しして確認できます。健康度や残り時間は参考値です。シャッター音強制設定の変更成功は、実際の撮影音が変わることを保証しません。

## インストールと更新

1. ReleaseからAPKをダウンロードします。
2. APKを開き、必要な場合は利用するブラウザやファイル管理アプリからのインストールを許可します。
3. Androidの確認画面でインストールします。
4. 初回の案内に沿ってShizukuを準備し、OneToolsへの権限を許可します。Shizukuの接続は後回しにもできます。

Shizukuの案内は [公式サイト](https://shizuku.rikka.app/) を参照してください。

今後の公開版は同じアプリID・公開用署名鍵を維持して配布します。更新する際は新しいAPKを開いて上書きしてください。開発用Debug版は署名が異なるため、公開版を上書きインストールできません。

**1.8.1では、アプリ内の最新版確認・APKダウンロードは未実装です。** 「情報」のアップデート欄は今後対応予定の案内です。現時点ではこのリポジトリのReleasesで確認してください。

## データとプライバシー

1.8.1にはINTERNET権限がなく、アプリ自身によるネットワーク通信や解析データの送信は行いません。外部サイト・ストアへのリンクは外部アプリで開き、そのサービスのポリシーが適用されます。

初期セットアップの完了状態と、端末更新履歴で選択した販売元を端末内に保存します。取得情報・実行ログはメモリ内で扱い、アプリ独自のバッテリー履歴は継続保存しません。
